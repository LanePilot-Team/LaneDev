# 楠梓路線展示網頁

展示頁包含汽車 17 條、機車 18 條路線，可同步觀看道路實景、Google Maps 與車道導航。影片沿用已定稿的起訖與同步時間。

## 使用完整 Windows 離線分享包

1. 向專案團隊取得 `楠梓路線_分享版_Windows_x64.zip`（約 15.9 GB）。
2. 在 Windows 10 或 11 的 x64 電腦上完整解壓。雙擊解壓資料夾中的「開啟網站.cmd」，並保持命令視窗開啟。
3. 瀏覽器會開啟 `http://127.0.0.1:18765/`。若沒有自動開啟，手動輸入該網址。

## 使用本分支的網站檔案

1. 安裝 Python 3，並下載或複製本分支。
2. 從同一版離線分享包取出完整的 `網站/media/`，放進本分支的 `網站/` 下。應有 `media/car/` 的 51 支影片與 `media/scooter/` 的 54 支影片。GitHub 的「Download ZIP」只包含分支檔案，完整影片由離線包提供。
3. 在分支根目錄開啟終端機，執行 `python server.py --open`。若系統使用 `python3` 指令，改為 `python3 server.py --open`。
4. 點頁首「檢查離線內容」，確認顯示汽車 51／51、機車 54／54。若數量不足，請檢查影片資料夾層級和檔名。

## 播放與故障排除

- 選擇汽車或機車，再選起終點或從「35組路線」清單選一條，按「觀看影片」。
- 三個畫面共用時間軸，可拖曳、調整速度、切換全螢幕及分別開關兩套導航的聲音。
- 部分實景使用 HEVC HDR。遇到黑畫面時可用支援 HEVC 的 Edge 或 Chrome 播放，並確認系統已安裝相應的解碼器。
- 展示前把整個資料夾放在本機硬碟，啟動後即使沒有網路也能從本機讀取影片。關閉終端機會停止網站。若 18765 連接埠被占用，先關閉已啟動的本機展示程式。
