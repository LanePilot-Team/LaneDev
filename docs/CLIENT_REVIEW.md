# Android 用戶端驗證與待確認事項

本次修改留在 `codex/android-standalone` 同一工作區，未提交或推送。
LaneDev 核心目標是以車道級道路、待轉區與 3D 路面資訊提供汽機車導航；
此分支把前端內建於 Android APK，以本機 HTTPS WebView 執行，不依賴開發伺服器。
本次將開發工具轉為唯讀用戶端，保留官方道路及待轉區作為導航輸入。

## 已修改範圍

1. 移除編輯、匯入與展示入口；打包排除 editor 模組，停用資料寫入與舊 localStorage 編輯覆蓋。Android 拒絕本機非 GET 資料請求。
2. 定位權限、系統定位開關檢查、目前位置按鈕；路線預設目前起點，支援自訂起終點。系統不允許 App 擅自打開 GPS，改提供系統設定入口。
3. 語音改接 Android TextToSpeech，中文語音可用狀態、下載／設定入口與試聽；不再依賴 Web Speech API。
4. 排除大眾運輸圖層、路由入口、資料檔及場站／共享單車 POI；保留停車場與一般地標。
5. 導航畫面縮短為方向、距離及簡短安全提醒，播報保留原本完整車道／道路文案，可關閉。
6. 導航視距 16–22 可選並保存，套用於導航、重新置中及重規劃。
7. 移除模擬駕駛、Demo 與速度倍率及其計時路徑。導航只依 GPS 更新；沒有以倍率推進車輛或動畫的功能。
8. 前景使用 Android rotation-vector 感測器取得手機方向；低速導航使用可靠且新鮮的朝向資料，無感測器時退回路線方向。

## 2026-09-17：搜尋規劃整合、定位朝向、語音與啟動診斷

本次只在同一本機工作區修改，未自動提交或推送。

- 主畫面只保留搜尋入口與定位／設定，移除舊右側工具列。搜尋目的地後按「路線」，起點預設目前位置。
- 起點、終點及新增停靠點均可直接打字搜尋，沿用同一組搜尋結果與地址顯示；更換任一端點只更新該端點並重新規劃，切換汽／機車重新計算。
- 移除「使用目前位置作起點」「自訂起終點」模式按鈕；「目前位置」保留在起點搜尋的建議選項，供自訂後恢復 GPS 使用。
- 定位標記改為藍點＋朝向扇形（隨地圖旋轉對齊）；無可靠／新鮮朝向時不顯示扇形。
- 地址不再回退為「休閒」等分類。來源有地址則完整顯示；缺漏時查詢 Android Geocoder，標示「附近地址（非確認門牌）」。離線、無 Geocoder 或查無資料時顯示地址缺漏及座標，不能保證每筆 POI 都有正式門牌，也不捏造地址。查詢由系統地理編碼服務處理地點座標，不另傳手機實際位置。
- 原 TTS 選聲音前未初始化語言、排除尚未下載聲音、返回設定時未強制重新載入；現改先 setLanguage，選中文聲音、提供真正的引擎資料下載入口，回到 App 重新初始化。首次引擎連線失敗可在播報時重試。
- 語音指定 navigation/speech 音訊用途、媒體音量控制；試聽不受導航靜音開關影響，顯示播放回呼與媒體音量，避免「開過設定就等於有語音」的假設。

### 為何 loading 很久

確實在手機執行大量前處理，但最慢的不是導航圖本身。以下是從地圖建構到路網可用的一次分段量測（不包含先前 Android 程序啟動；非真實手機 benchmark）：

| 階段 | 耗時 |
| --- | ---: |
| 地圖樣式載入 | 3.94 秒 |
| 路面圖示解碼 | 0.45 秒 |
| 讀取／解析本機資料 | 1.42 秒 |
| 建築整理 | 0.004 秒 |
| 道路幾何前處理 | 7.91 秒 |
| Lane Base 套用 | 0.30 秒 |
| 官方 journal 與道路接合 | 0.54 秒 |
| 路面幾何生成／送入繪圖來源 | 5.21 秒 |
| 導航圖建立 | 0.45 秒 |
| 待轉區生成／繪製 | 11.13 秒 |
| 標線、路口、文字與繪圖路網 | 2.65 秒 |
| 3D 模型初始化 | 0.28 秒 |
| 合計 | 約 34.3 秒 |

同日再次啟動量測約 24.2 秒，其中待轉區仍約 12.1 秒；環境暖機、系統快取和負載會影響數字，這不是本次做過啟動效能優化的證據。

這些同步計算主要在 WebView 主執行緒，loading 動畫也可能停頓。
本次只加入分段計時，沒有擅自改計算結果。建議另案將固定道路／待轉區／標線預先在建置期計算，
再考慮資料版本快取與 Worker；應先比較結果一致性，不能只刪掉計算或拿掉 loading。
