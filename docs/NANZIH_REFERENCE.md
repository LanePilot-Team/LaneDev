# 楠梓路線參考資料

`web-source/src/core/nanzihRouteData.json` 保存「楠梓路線」網站版本 16 的 35 組汽車／機車有向路線，包括道路中心線、路段方向和網站顯示的車道線。來源網站：<https://nanzih-route-lab-20261108.annahung945.chatgpt.site/>；網站來源提交為 `7e50f95993bbfefe7a82408bc618dcae21c57369`，道路來源為 LaneDev `610d4670d7b72933ff0fffc215f64e15f63048c1`。

一般兩點規劃中，起終點分別位於網站五個地點 30 公尺內且存在該車種及方向的示範時，使用該示範的有向道路和畫線。網站沒有列出的組合、其他地點及含停靠點的路線，仍由一般路網規劃。偏航後使用一般重新規劃；它可能與原示範路線不同。若參考路段無法映射到目前路網，顯示規劃失敗，不自動宣稱符合示範。

機車由中油往楠梓車站使用的約 16 公尺連接，是網站依使用者確認補繪的近似線形；導航用資料在執行期加入，官方來源道路資料不變。依使用者確認，對指定路段和方向調整汽車／機車通行標記。參考路線與既有轉向箭頭衝突時，沿網站路線行進，車道選擇標示為推估，並非網站提供了車道級實測資料。

修改路網後，必須重新核對 35 組道路對應及畫線，並依根目錄 `AGENTS.md` 重新產生 Android assets、執行測試。實機定位、偏航重算與真實道路駕駛仍需要在現場驗證。
