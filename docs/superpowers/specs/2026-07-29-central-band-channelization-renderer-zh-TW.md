# 中央帶槽化繪製規格

## 目標

槽化帶的主資料來源是既有的車道編輯，而不是另一套獨立圖形。編輯者設定中央帶寬度、中央帶類型、兩端偏心道用途，以及單邊使用時的處理方式；地圖依這些設定以同一套公尺幾何繪製。自動偵測只在沒有人工設定時提供預設值。

## 現有設定與優先順序

路段區塊既有欄位依序為：`center_m`、`center_kind`、兩端 `turn_bay` 用途，以及 `single_mode`。人工 journal 設定永遠優先於自動推論；沒有人工設定才允許自動判定偏心道與其樣式。不得因為獨立的槽化設定而改變車道用途。

## 繪圖結果

| 中央帶與兩端用途 | 繪圖結果 |
| --- | --- |
| 兩端皆使用偏心道 | 兩條中央雙黃線平滑 S 型換位；不強制加入三角槽化面。 |
| 僅一端使用，`single_mode=capped` | 在**沒有左轉車道的一側**畫一個三角槽化面。三角尖端是實際左轉道分出的漸變起點；另一端貼到該進入方向的停止線前中央帶雙黃線邊界。不得覆蓋箭頭、左轉儲車道或其他可通行車道。 |
| 僅一端使用，`single_mode=ignore` | 不畫槽化面；中央雙黃線固定在讓已使用偏心道可通行的位置。 |
| 兩端皆不使用、中央帶類型為槽化 | 在中央帶全長畫純槽化帶，並以路口淨空裁切。 |
| 中央帶類型為實體島 | 交由分隔島 renderer；此規格不取代實體島。 |

## 幾何與樣式

三角槽化面的兩條側邊分別是：偏心道漸變雙黃線，以及其對側的固定中央帶雙黃線。靠路口一端以停止線前的中央帶雙黃線作封口。斜紋僅落在該三角形內，以 `TAIWAN_YELLOW_HATCH_V1` 統一規格（線寬 0.18m、節距 1.25m、內縮 0.30m）；不同長寬不改變密度或粗細。

## 自動與人工

自動偵測只產生等同人工設定的有效中央帶／偏心道組合，並以相同 renderer 畫出。人工在既有車道編輯調整中央帶或單／雙邊用途後，應立即重繪相同樣式；偏心道面板仍可用來確認例外的左轉用途，但不應另行決定槽化面左右側。

## 驗收

1. A 區單邊封口的槽化面從左轉道分出尖端開始，止於停止線前的中央帶雙黃線，且不壓入左轉箭頭與左轉車道。
2. 順向與逆向的單邊封口互為鏡像。
3. 雙邊使用維持 S 型，無強制三角槽化面。
4. 純槽化帶與三角槽化面都使用同一斜紋密度與線寬。
5. 車道編輯與自動偵測對相同設定產生相同幾何。
