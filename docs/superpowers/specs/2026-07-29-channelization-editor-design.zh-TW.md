# 槽化帶編輯器與一致斜紋繪製設計

## 目標

把槽化帶提升為可檢視、可保存的道路標線資料。系統保留自動辨別並產生合理預設；編輯者則可新增、調整、覆寫或停用個別槽化區。無論槽化區長寬如何，均採同一份繪製規格。

## 現況

`buildChannelization()` 目前依合併後道路的 `centerKind`、`centerM` 與自動產生的 `turn_bay` 紀錄推導黃線與槽化斜紋。編輯器能設定中央帶與偏心道，也已有單邊使用的「封口／完全忽略」選項，但尚不能獨立建立或編輯槽化區。斜紋現由多條程式路徑產生，間距假設並不完全一致。

## 範圍

- 保留自動偏心道與槽化帶辨別。
- 新增可保存的 `channelization` enhancement 紀錄與專屬地圖工具。
- 所有黃色槽化區統一使用一份公尺制繪製樣式。
- 把最初圖片紅線代表的「未使用側封閉」做成通用、依道路計算的幾何。
- 保留既有 `road`、`turn_bay` journal 紀錄及其行為。

不包含：自由手繪多邊形、改變導航規則、或改變實體分隔島的交通語意。

## 資料模型

新增 `target.type = 'channelization'`。每筆紀錄錨定在道路區塊，而不是螢幕座標：

```ts
{
  target: { type: 'channelization', key: 'way/W@b/N#channel/C' },
  fields: {
    present: 1,
    mode: 'auto' | 'manual' | 'override' | 'disabled',
    s_start_m: number,
    s_end_m: number,
    width_start_m: number,
    width_end_m: number,
    side: 'forward' | 'backward' | 'center',
    closure: 'none' | 'unused-side',
    style: 'taiwan-yellow-hatch-v1'
  }
}
```

`s_start_m`、`s_end_m` 是沿所選道路區塊的公尺里程；寬度在兩端之間線性變化。因此直線、彎道、不同縮放與不同投影下都能得到穩定的漸寬／漸窄槽化面。

自動候選也會先正規化成相同形狀。人工 `override` 取代對應自動候選；`disabled` 停用自動候選但保留歷程；`manual` 則是沒有自動前身的人工新增區。

## 繪製樣式：`taiwan-yellow-hatch-v1`

- 黃色邊界與封口線沿用既有道路標線色系。
- 斜紋線寬、中心間距與傾角只在同一個渲染器以全域常數定義。
- 斜紋位置以沿道路的公尺里程取樣，絕不依幾何取樣點數或當地帶寬推算。
- 每條斜紋都裁切於計算後的槽化多邊形內，並與兩側邊界保留內縮距離。
- 合法但短或窄的區域置中畫一條自適應斜紋；窄於最小可視寬度時只畫邊界／封口線。
- 所有槽化斜紋由同一渲染器負責；偏心道只提供幾何與所屬關係，避免重複或混合密度。

## 通用未使用側封閉（最初圖片的紅線樣式）

單側偏心道使用 `closure: 'unused-side'` 時，未使用側建立為漸變槽化區：

1. 從有效偏心道漸變段起點開始。
2. 沿固定與移動中的黃色邊界，構成未使用側多邊形。
3. 於路口淨空線或有效偏心道入口中較上游者結束。
4. 在仍有寬度的端點補上橫向封口線。
5. 以 `taiwan-yellow-hatch-v1` 繪製該多邊形。

此作法不依範例圖片的長寬：道路可短、長、窄、寬、彎或直，均採相同建構方式與樣式。

## 編輯器行為

在既有車道、待轉區、偏心道工具旁新增「槽化帶」工具。

- 選取道路區塊後，顯示自動候選與既有人工紀錄。
- 編輯者可接受自動候選、停用它，或建立覆寫。
- 新增人工槽化區時，以貼齊道路區塊的起迄把手與兩端寬度控制器調整。
- 可設定所屬側與封閉類型；`unused-side` 顯示等同紅線補足的封閉幾何，`none` 為一般槽化帶。
- 儲存、匯出、靜態道路資料庫持久化與 journal 折疊，均將 `channelization` 視為其他 enhancement 類型處理。

## 驗收案例與視覺證據

每個案例均保存未改動基準圖與改動後圖，中心點與縮放完全一致；另保留一次人工新增或覆寫狀態，證明不是只依靠自動判定。

| 案例 | 位置 | 必須驗證 |
|---|---|---|
| A | 藍田路 745 巷以西 | 長中央帶；比較自動斜紋、單側封閉與長度上的密度。 |
| B | 援中路 × 德中路（`22.72114, 120.28026`） | 短且斜交的進入段；封口與斜紋不得跨越路口淨空。 |
| C | 援中路 × 藍昌路（`22.72520, 120.29150`） | 複雜進入段；人工覆寫在不均等可用長度下仍須貼齊。 |

## 測試

- 單元測試：紀錄正規化、漸變多邊形、以公尺取樣的間距、斜紋裁切、短窄回退、覆寫優先序與停用自動候選。
- 既有偏心道測試：不得重複產生斜紋，導航／偏心道語意不得改變。
- 在隔離功能分支執行建置與目標測試。
- 視覺審閱：A、B、C 三處的改動前／改動後／人工編輯圖。
